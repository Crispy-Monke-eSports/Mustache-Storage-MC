# Mustache Storage

[![Optimize Resource Pack](https://github.com/Bjorkan/Mustache-Storage-MC/actions/workflows/optimize.yml/badge.svg)](https://github.com/Bjorkan/Mustache-Storage-MC/actions/workflows/optimize.yml)  [![Publish new release](https://github.com/Bjorkan/Mustache-Storage-MC/actions/workflows/publish.yml/badge.svg)](https://github.com/Bjorkan/Mustache-Storage-MC/actions/workflows/publish.yml)


The pack adds a mustache to the single- and double chest. More storage blocks like dispensers may follow, but we will see!

Best used with Faithful 32x installed aswell! **However** this resource pack needs to be placed above Faithful in the resource pack list to be displayed in-game!

## Supported Minecraft Java versions

This pack declares compatibility with **Minecraft Java Edition 1.13 through 26.3** (inclusive). Minecraft 26.3 uses resource-pack format **97.1**.

| Minecraft Java version | Resource-pack format | Compatibility handling |
| --- | --- | --- |
| 1.13–1.20.1 | 4–15 | Older clients can load the textures, but may show an outdated/newer-pack warning because they only check `pack_format`. |
| 1.20.2–1.21.8 | 18–64 | `supported_formats` declares support for legacy format versions through 64. |
| 1.21.9–26.3 | 69.0–97.1 | `min_format` / `max_format` declare the full version range, including 26.3. |

Only the normal single and double chest textures are modified; copper, trapped, and ender chests are not included. Declared compatibility and texture-path checks do not replace an in-game visual test on each release.

## Wait, why? 🤨

Well why not? Give Minecraft some personality and show your family and friends your Minecraft chests are fancier than theirs.
